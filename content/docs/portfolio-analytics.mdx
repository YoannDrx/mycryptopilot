# Portfolio data and freshness

The portfolio is read-only. It separates:

- current balances and total equity;
- realized PnL from closed activity;
- unrealized PnL from open exposure;
- historical performance calculated from synchronized trades.

Each live value should be read together with its exchange source and last
synchronization time. A stale or failed synchronization remains visible rather
than being replaced by an invented value.

## Demo data

When no exchange is connected, a deterministic dataset may illustrate the UI.
It is labelled **Example** or **Demo / Testnet** and must not be interpreted as
an account, trader or market performance.

## Limitations

Exchange APIs can be delayed, temporarily unavailable or differ in how they
report fees and realized PnL. MyCryptoPilot exposes those limits and does not
guarantee tax, accounting or trading accuracy. Export data and reconcile it
against the exchange before making a decision.
