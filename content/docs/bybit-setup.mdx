# Connect Bybit read-only

Create a dedicated API key in Bybit API Management and select **Read-Only**.
Do not enable SpotTrade, SpotConvert, Order, Position, transfer or withdrawal
permissions.

## Fail-closed validation

MyCryptoPilot requires both:

- Bybit's explicit read-only indicator;
- no trading scope in the returned permissions list.

A contradictory response — for example `readOnly: 1` together with `Order` —
is rejected. Network errors and missing permission metadata are also rejected.

## Lifecycle

Only one exchange connection is supported per account. Disconnect the current
one before switching. To revoke access completely, disconnect in MyCryptoPilot
and delete the key in Bybit.

The product reads balances and historical activity only. It never creates,
updates or cancels an order.
