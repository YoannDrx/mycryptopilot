"Combien dois-je investir sur ce trade ?" C'est LA question que se posent tous les traders. La réponse n'est PAS "10% de mon capital" ni "1000$". C'est une formule mathématique précise basée sur votre **risque maximum acceptable**. Bienvenue dans l'univers du **position sizing**, la compétence qui sépare les amateurs des professionnels.

## Qu'est-ce que le Position Sizing ?

Le **position sizing** (dimensionnement de position) est le calcul de la **taille exacte en USDT/USD** à investir sur un trade donné, basé sur :

1. Votre **capital total**
2. Le **pourcentage de risque** que vous acceptez
3. La **distance de votre stop-loss**

**Ce n'est PAS** :
- ❌ "Je mets toujours 10% de mon capital"
- ❌ "Je tradela toujours 0.1 BTC"
- ❌ "Selon ma conviction (plus je suis sûr, plus je mets)"

**C'est** :
- ✅ Calculer mathématiquement pour risquer exactement 1-2% du capital
- ✅ Ajuster la taille selon la distance du stop-loss
- ✅ Protéger le capital de manière systématique

## Pourquoi le Position Sizing est Crucial

### L'Erreur Fatale du Débutant

**Trader A** (sans position sizing) :
- Capital : 10,000$
- Trade 1 : Achète pour 5,000$ de BTC, SL à -10% → perte 500$ (-5% capital)
- Trade 2 : Achète pour 5,000$ d'ETH, SL à -5% → perte 250$ (-2.5% capital)
- Trade 3 : Achète pour 4,000$ de SOL, SL à -15% → perte 600$ (-6% capital)
- **Total pertes** : 1,350$ (-13.5% capital) en **3 trades**

**Trader B** (avec position sizing pour 2% risque) :
- Capital : 10,000$
- Trade 1 : Calcul → 2,000$ de BTC, SL à -10% → perte 200$ (-2% capital)
- Trade 2 : Calcul → 4,000$ d'ETH, SL à -5% → perte 200$ (-2% capital)
- Trade 3 : Calcul → 1,333$ de SOL, SL à -15% → perte 200$ (-2% capital)
- **Total pertes** : 600$ (-6% capital) en **3 trades**

**Résultat** : Trader B perd **2.25× moins** avec le même nombre de pertes, grâce au position sizing.

### Survie Mathématique

| Perte Totale | Capital Restant | Gain Nécessaire pour Récupérer |
|--------------|-----------------|-------------------------------|
| -5%          | 95%             | +5.3%                         |
| -10%         | 90%             | +11.1%                        |
| -20%         | 80%             | +25%                          |
| -50%         | 50%             | +100%                         |

**Position sizing contrôle vos pertes** → vous gardez votre capital → vous pouvez continuer à trader → vous finissez profitable.

## La Formule Fondamentale du Position Sizing

### Formule de Base

```
Taille Position (USDT) = (Capital × % Risque) / (% Distance Stop-Loss)
```

**Où** :
- **Capital** : Total de votre capital trading
- **% Risque** : Pourcentage que vous acceptez de perdre (1-2%)
- **% Distance SL** : Pourcentage entre entry et stop-loss

### Exemple Concret Pas à Pas

**Données** :
- Capital total : **10,000 USDT**
- Risque accepté : **2%** = 200 USDT max
- Trade : LONG BTC/USDT
- Entry : **42,000$**
- Stop-Loss : **40,500$**

**Étape 1 : Calculer le % Distance Stop-Loss**

```
% Distance SL = (Entry - Stop-Loss) / Entry × 100
% Distance SL = (42,000 - 40,500) / 42,000 × 100
% Distance SL = 1,500 / 42,000 × 100
% Distance SL = 3.57%
```

**Étape 2 : Calculer la Taille de Position**

```
Taille = (Capital × % Risque) / (% Distance SL)
Taille = (10,000 × 0.02) / 0.0357
Taille = 200 / 0.0357
Taille = 5,602 USDT
```

**Étape 3 : Calculer le Nombre de BTC**

```
Nombre BTC = Taille / Entry Price
Nombre BTC = 5,602 / 42,000
Nombre BTC = 0.1334 BTC
```

**Vérification** :
- Position : 0.1334 BTC × 42,000$ = **5,602 USDT**
- Si SL touché à 40,500$ : 0.1334 BTC × 40,500$ = **5,402 USDT**
- Perte = 5,602 - 5,402 = **200 USDT** ✅ (exactement 2% du capital)

## Position Sizing pour Différents Scénarios

### Scénario 1 : Stop-Loss Serré (1-2%)

**Trade** : LONG ETH
- Entry : 2,500$
- SL : 2,450$ (-2%)

**Position sizing** :
```
Taille = (10,000 × 0.02) / 0.02 = 200 / 0.02 = 10,000 USDT
```

**Attention** : Votre capital total est 10,000$, donc vous mettriez 100% → **DANGER !**

**Solution** : Règle de sécurité → **jamais plus de 20-30% du capital sur un trade**, même si le calcul le permet.

**Ajustement** :
- Max position autorisée : 3,000 USDT (30% capital)
- Risque réel : (3,000 × 0.02) = 60 USDT (0.6% capital au lieu de 2%)

**Trade sûr, mais gain/perte réduits proportionnellement.**

### Scénario 2 : Stop-Loss Large (10%+)

**Trade** : LONG Altcoin volatile
- Entry : 10$
- SL : 8.50$ (-15%)

**Position sizing** :
```
Taille = (10,000 × 0.02) / 0.15 = 200 / 0.15 = 1,333 USDT
```

**Vous achetez pour seulement 1,333$ (13% capital)** car le SL est large.

**Raison** : Un SL à -15% nécessite moins de capital pour respecter le risque de 200$.

### Scénario 3 : Capital Variable (Drawdown)

**Situation** : Après quelques pertes, votre capital est passé de 10,000$ à 9,200$.

**Ajustement** :
- Nouveau risque 2% = 9,200 × 0.02 = **184 USDT** (plus 200$)

**Trade** : LONG BTC
- Entry : 43,000$
- SL : 41,500$ (-3.5%)

**Position sizing** :
```
Taille = (9,200 × 0.02) / 0.035 = 184 / 0.035 = 5,257 USDT
```

**Important** : Votre taille de position **diminue** quand votre capital diminue. C'est normal et sain. Cela vous protège d'une spirale de pertes.

### Scénario 4 : Perpetuals avec Levier

**Trade** : SHORT BTC PERP avec levier ×3
- Entry : 44,000$
- SL : 45,500$ (+3.4%)
- Capital : 10,000$
- Risque : 2% = 200$

**ATTENTION** : Avec levier, la formule change !

**Formule avec levier** :
```
Taille Notional = (Capital × % Risque × Levier) / % Distance SL
Taille Margin = Taille Notional / Levier
```

**Calcul** :
```
Taille Notional = (10,000 × 0.02 × 3) / 0.034 = 600 / 0.034 = 17,647 USDT
Taille Margin = 17,647 / 3 = 5,882 USDT (marge requise)
```

**Vérification** :
- Position notionnelle : 17,647$
- Avec levier ×3 : besoin de 5,882$ de marge
- Si SL touché (+3.4%) : perte = 17,647 × 0.034 = 600$ → mais avec levier ×3, perte réelle = 600 / 3 = **200$** ✅

**CONSEIL** : Le levier est complexe. Si débutant, restez en SPOT (pas de levier) pendant 6 mois minimum.

## Calcul du Position Sizing : Méthode Alternative (Fixe en $)

Certains traders préfèrent fixer le **montant en $ risqué** plutôt qu'un pourcentage.

### Formule Alternative

```
Taille = Risque Fixe ($) / Distance SL ($)
```

**Exemple** :
- Vous voulez risquer **200$** maximum
- Trade : LONG BTC à 42,000$
- SL : 40,500$ (distance = 1,500$)

**Calcul** :
```
Taille = 200 / 1,500 = 0.1333 BTC
0.1333 BTC × 42,000$ = 5,599 USDT
```

**Même résultat que la formule en pourcentage.**

## Les Pièges du Position Sizing à Éviter

### Piège 1 : Taille Fixe ("Je trade toujours X$")

**Erreur** :
- Trade A : 1,000$ de BTC, SL à -5% → risque 50$
- Trade B : 1,000$ d'Altcoin, SL à -20% → risque 200$

**Trade B risque 4× plus que Trade A !**

**Solution** : Utilisez la formule basée sur le SL, pas une taille arbitraire.

### Piège 2 : Pourcentage du Capital ("10% du capital")

**Erreur** :
- Capital : 10,000$
- "Je mets 10%" = 1,000$ sur chaque trade
- Trade avec SL -15% → risque réel = 150$ (1.5% capital)
- Trade avec SL -3% → risque réel = 30$ (0.3% capital)

**Incohérence totale** : votre risque varie de 0.3% à 1.5% sans raison.

**Solution** : Fixez le % risque (2%), pas le % capital investi.

### Piège 3 : "Conviction Trading"

**Erreur** :
- "Je suis SÛR que BTC va monter → je mets 50% de mon capital"
- Si erreur (et le marché s'en fout de votre conviction) → perte massive

**Solution** : Votre "conviction" ne change PAS la taille. Elle change la **décision de prendre ou non le trade**. Une fois décidé, respectez le position sizing.

### Piège 4 : Ignorer la Limite Maximale (20-30%)

Même si le calcul dit "vous pouvez mettre 100% du capital", **ne le faites jamais**.

**Règle de sécurité** :
- Max 20% capital pour traders avancés
- Max 10% capital pour débutants
- Si le calcul donne plus → réduisez le risque % (passez de 2% à 1% ou 0.5%)

### Piège 5 : Ne Pas Ajuster quand le Capital Change

**Erreur** :
- Capital initial : 10,000$ → risque 200$ (2%)
- Après profits : 12,000$ → toujours risque 200$ → **maintenant 1.67%**

**Problème** : Vous sous-utilisez votre capital.

**Solution** : Recalculez le risque $ à chaque trade :
- Si capital = 12,000$ et risque 2% → risque = 240$

**Fréquence** : Recalcul hebdomadaire ou après gain/perte > 10%.

## Position Sizing Avancé

### Technique 1 : Kelly Criterion

Le **Kelly Criterion** calcule la taille optimale pour maximiser la croissance long terme.

**Formule** :
```
Kelly % = (Win Rate × Avg Win) - (Loss Rate × Avg Loss) / Avg Win
```

**Exemple** :
- Win rate : 55%
- Avg win : +4%
- Avg loss : -2%

**Calcul** :
```
Kelly = (0.55 × 4) - (0.45 × 2) / 4 = (2.2 - 0.9) / 4 = 0.325 = 32.5%
```

**Kelly suggère : 32.5% du capital** (très agressif !)

**Problème** : Kelly assume win rate et R/R constants (jamais le cas en réalité). Un mauvais streak avec 32% risque = ruine.

**Solution** : Utilisez **Half-Kelly ou Quarter-Kelly** :
- Half-Kelly : 32.5% / 2 = **16.25%**
- Quarter-Kelly : 32.5% / 4 = **8%**

**Pour qui** : Traders avancés (2+ ans) avec stats solides sur 200+ trades.

### Technique 2 : Volatility-Based Sizing

Ajustez la taille selon la **volatilité** de la crypto.

**Principe** :
- BTC (faible volatilité) : risque 2%
- Altcoin large cap (ETH, SOL) : risque 1.5%
- Small cap (haute volatilité) : risque 0.5-1%

**Raison** : Les small caps peuvent faire -30% en une journée. Même avec SL, le slippage peut être énorme.

### Technique 3 : Scaling (Entrée Progressive)

Au lieu d'entrer 100% position d'un coup :

**Exemple** :
- Capital : 10,000$
- Risque total : 2% = 200$
- Calculer taille pour 200$ → 5,600$

**Split en 3 entrées** :
- Entry 1 (42,000$) : 2,800$ (50%)
- Entry 2 (41,500$) : 1,680$ (30%)
- Entry 3 (41,000$) : 1,120$ (20%)

**SL unique** : 40,500$ pour toute la position

**Avantage** : Prix moyen optimisé si pullback
**Inconvénient** : Si prix part sans pullback, vous entrez partiellement

## Position Sizing et Psychologie

### Le "Comfortable Bet"

**Exercice** : Quelle taille de position vous permet de **dormir tranquille** ?

- Si vous checkez le prix toutes les 5 minutes → position trop grosse
- Si une perte de ce trade vous stresse → position trop grosse
- Si vous priez pour que ça monte → position trop grosse

**La bonne taille** : Celle où, si SL touché, vous vous dites "OK, next trade" sans émotion forte.

**Souvent, c'est < 2% de risque** pour débutants. Et c'est OK ! Commencez à 0.5-1% si besoin.

### Éviter le "Round Number Bias"

**Biais** : Trader en "nombres ronds" (1000$, 0.1 BTC, 100 coins...).

**Problème** : Ces nombres n'ont aucun lien avec votre risk management.

**Solution** : Acceptez les nombres "bizarres" (5,602$, 0.1334 BTC). C'est le résultat du calcul scientifique.
